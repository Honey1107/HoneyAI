
## 🔄 Basic Git Workflow

Check the current repository status:

```bash
git status
```

Stage the changes:

```bash
git add .
```

Create a commit:

```bash
git commit -m "Update Python practice"
```

Push the changes to GitHub:

```bash
git push
```
